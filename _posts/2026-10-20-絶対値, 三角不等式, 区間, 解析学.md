## 1. 絶対値の基本性質
## 1. 절댓값의 기본 성질

### 1.1 絶対値の定義
### 1.1 절댓값의 정의

実数 $a$ の絶対値 $\lvert a \rvert$ は、$a \ge 0$ のとき $\lvert a \rvert = a$、$a < 0$ のとき $\lvert a \rvert = -a$ と定義される。  
실수 $a$ 의 절댓값 $\lvert a \rvert$ 는 $a \ge 0$ 일 때 $\lvert a \rvert = a$, $a < 0$ 일 때 $\lvert a \rvert = -a$ 로 정의된다.

また、平方根を用いると絶対値は次のように表せる。  
또한 제곱근을 이용하면 절댓값은 다음과 같이 나타낼 수 있다.

$$\lvert x \rvert = \sqrt{x^2}$$

### 1.2 定理2（積の絶対値）
### 1.2 정리 2 (곱의 절댓값)

すべての実数 $a, b$ に対して、次の等式が成り立つ。  
모든 실수 $a, b$ 에 대하여 다음 등식이 성립한다.

$$\lvert ab \rvert = \lvert a \rvert \lvert b \rvert$$

**証明**  
**증명**

$\lvert x \rvert = \sqrt{x^2}$ を使うと、正と負の場合分けをせずに証明できる。  
$\lvert x \rvert = \sqrt{x^2}$ 를 사용하면 양수와 음수의 경우를 나누지 않고 증명할 수 있다.

$$\lvert ab \rvert = \sqrt{(ab)^2} = \sqrt{a^2 b^2} = \sqrt{a^2}\sqrt{b^2} = \lvert a \rvert \lvert b \rvert$$

よって定理2が成り立つ。□  
따라서 정리 2가 성립한다. □

### 1.3 定理3（三角不等式）
### 1.3 정리 3 (삼각부등식)

すべての実数 $a, b$ に対して、次の不等式が成り立つ。  
모든 실수 $a, b$ 에 대하여 다음 부등식이 성립한다.

$$\lvert a + b \rvert \le \lvert a \rvert + \lvert b \rvert$$

これは解析学において非常に大切な不等式であり、三角不等式とよばれる。  
이것은 해석학에서 매우 중요한 부등식이며, 삼각부등식이라고 불린다.

**証明**  
**증명**

まず、すべての実数 $a, b$ に対して次が成り立つ。  
먼저 모든 실수 $a, b$ 에 대하여 다음이 성립한다.

$$ab \le \lvert ab \rvert = \lvert a \rvert \lvert b \rvert$$

両辺を2倍すると、次の不等式を得る。  
양변에 2를 곱하면 다음 부등식을 얻는다.

$$2ab \le 2\lvert a \rvert \lvert b \rvert$$

したがって、$(a+b)^2$ は次のように評価できる。  
따라서 $(a+b)^2$ 은 다음과 같이 평가할 수 있다.

$$(a+b)^2 = a^2 + 2ab + b^2 \le a^2 + 2\lvert a \rvert \lvert b \rvert + b^2 = \left(\lvert a \rvert + \lvert b \rvert\right)^2$$

両辺はともに $0$ 以上なので、平方根をとっても大小関係は変わらない。  
양변은 모두 $0$ 이상이므로 제곱근을 취해도 대소 관계는 변하지 않는다.

$$\sqrt{(a+b)^2} \le \sqrt{\left(\lvert a \rvert + \lvert b \rvert\right)^2}$$

ゆえに $\lvert a + b \rvert \le \lvert a \rvert + \lvert b \rvert$ が成り立つ。□  
그러므로 $\lvert a + b \rvert \le \lvert a \rvert + \lvert b \rvert$ 가 성립한다. □

**直観的な意味**  
**직관적인 의미**

実数の絶対値は、数直線上の原点からの距離と考えることができる。  
실수의 절댓값은 수직선 위에서 원점으로부터의 거리로 생각할 수 있다.

したがって三角不等式は「寄り道をした道のりは、直接結んだ距離より短くならない」という距離の基本性質を表している。  
따라서 삼각부등식은 "돌아서 간 경로의 길이는 직접 이은 거리보다 짧아질 수 없다"는 거리의 기본 성질을 나타낸다.

数値例として、次のような計算ができる。  
수치 예로 다음과 같이 계산할 수 있다.

$$\lvert 3 + (-5) \rvert = 2 \le 3 + 5 = 8$$

この定理は、今後、極限・数列の収束・連続性・コーシー列などの証明で繰り返し使われる。  
이 정리는 앞으로 극한, 수열의 수렴, 연속성, 코시 수열 등의 증명에서 반복적으로 사용된다.

### 1.4 例題1（絶対値を含む方程式）
### 1.4 예제 1 (절댓값이 포함된 방정식)

次の等式を満足する $x$ を求めよ。  
다음 등식을 만족하는 $x$ 를 구하여라.

$$\lvert x + 1 \rvert = 2$$

**解**  
**풀이**

絶対値の意味から、$x + 1 = 2$ または $x + 1 = -2$ の2つの場合に分けて解く。  
절댓값의 의미로부터 $x + 1 = 2$ 또는 $x + 1 = -2$ 의 두 가지 경우로 나누어 푼다.

第1の場合は $x + 1 = 2$ より $x = 1$ となる。  
첫 번째 경우는 $x + 1 = 2$ 로부터 $x = 1$ 이 된다.

第2の場合は $x + 1 = -2$ より $x = -3$ となる。  
두 번째 경우는 $x + 1 = -2$ 로부터 $x = -3$ 이 된다.

$$x = 1 \quad \text{or} \quad x = -3$$

答は $x = 1$ または $x = -3$ である。  
답은 $x = 1$ 또는 $x = -3$ 이다.

## 2. §2 不等式と区間
## 2. §2 부등식과 구간

### 2.1 区間の種類
### 2.1 구간의 종류

不等式を満足する数の範囲を示すために、区間という用語を準備しておく。  
부등식을 만족하는 수의 범위를 나타내기 위해 구간이라는 용어를 준비해 둔다.

$a < b$ とする。$a$ と $b$ の間にあるすべての実数の集まりを開区間とよび、$(a, b)$ で表す。  
$a < b$ 라고 하자. $a$ 와 $b$ 사이에 있는 모든 실수의 모임을 열린구간(개구간)이라고 부르며 $(a, b)$ 로 나타낸다.

$$(a, b) = \lbrace x \mid a < x < b \rbrace$$

開区間は両端点 $a, b$ をどちらも含まない。  
열린구간은 양 끝점 $a, b$ 를 모두 포함하지 않는다.

両端点を含める場合は閉区間とよび、$[a, b]$ で表す。  
양 끝점을 포함하는 경우는 닫힌구간(폐구간)이라고 부르며 $[a, b]$ 로 나타낸다.

$$[a, b] = \lbrace x \mid a \le x \le b \rbrace$$

端点の一方だけを含める区間を半閉区間という。  
끝점 중 한쪽만 포함하는 구간을 반닫힌구간(반폐구간)이라고 한다.

$$[a, b) = \lbrace x \mid a \le x < b \rbrace, \qquad (a, b] = \lbrace x \mid a < x \le b \rbrace$$

最後に、一方が限りなく続く区間を無限区間という。  
마지막으로 한쪽이 끝없이 이어지는 구간을 무한구간이라고 한다.

$$[a, \infty) = \lbrace x \mid x \ge a \rbrace, \qquad (-\infty, b) = \lbrace x \mid x < b \rbrace$$

$(a, \infty)$ や $(-\infty, b]$ なども同様に定義される。  
$(a, \infty)$ 나 $(-\infty, b]$ 등도 마찬가지로 정의된다.

記号の丸かっこ $(\ )$ は端点を含まないこと、角かっこ $[\ ]$ は端点を含むことを表す。  
기호에서 소괄호 $(\ )$ 는 끝점을 포함하지 않음을, 대괄호 $[\ ]$ 는 끝점을 포함함을 나타낸다.

### 2.2 例題2（絶対値を含む不等式）
### 2.2 예제 2 (절댓값이 포함된 부등식)

次の不等式を満足する $x$ の範囲を求めよ。  
다음 부등식을 만족하는 $x$ 의 범위를 구하여라.

$$\lvert x \rvert \le 4$$

**解**  
**풀이**

絶対値の定義に従い、$x \ge 0$ と $x < 0$ の場合に分けて考える。  
절댓값의 정의에 따라 $x \ge 0$ 인 경우와 $x < 0$ 인 경우로 나누어 생각한다.

最初に $x \ge 0$ のとき、$\lvert x \rvert = x$ なので $0 \le x \le 4$ となる。  
먼저 $x \ge 0$ 일 때 $\lvert x \rvert = x$ 이므로 $0 \le x \le 4$ 가 된다.

次に $x < 0$ のとき、$\lvert x \rvert = -x$ なので $-x \le 4$ となる。  
다음으로 $x < 0$ 일 때 $\lvert x \rvert = -x$ 이므로 $-x \le 4$ 가 된다.

両辺に $-1$ を掛けると不等号の向きが逆になるので、$-4 \le x < 0$ を得る。  
양변에 $-1$ 을 곱하면 부등호의 방향이 바뀌므로 $-4 \le x < 0$ 을 얻는다.

2つの場合を合わせると、解は次のようになる。  
두 경우를 합치면 해는 다음과 같다.

$$-4 \le x \le 4 \quad \Longleftrightarrow \quad x \in [-4, 4]$$

### 2.3 覚えておくべき同値関係
### 2.3 꼭 기억할 동치 관계

$a > 0$ のとき、次の同値関係が成り立つ。  
$a > 0$ 일 때 다음 동치 관계가 성립한다.

$$\lvert x \rvert \le a \iff -a \le x \le a$$

$$\lvert x \rvert < a \iff -a < x < a$$

特に、解析学でよく現れる不等式は次のように書き換えられる。  
특히 해석학에서 자주 나오는 부등식은 다음과 같이 바꿔 쓸 수 있다.

$$\lvert x - a \rvert < \varepsilon \iff a - \varepsilon < x < a + \varepsilon$$

これは「$x$ と $a$ の距離が $\varepsilon$ より小さい」ことを意味している。  
이것은 "$x$ 와 $a$ 사이의 거리가 $\varepsilon$ 보다 작다"는 것을 의미한다.

この書き換えは、数列の極限や関数の連続性を定義する $\varepsilon$-$\delta$ 論法の基礎となる。  
이 변환은 수열의 극한과 함수의 연속성을 정의하는 $\varepsilon$-$\delta$ 논법의 기초가 된다.

## 3. 練習問題 22〜27（証明）
## 3. 연습문제 22~27 (증명)

以下では、絶対値の定義・三角不等式・不等式の基本法則のみを用いて証明する。  
아래에서는 절댓값의 정의, 삼각부등식, 부등식의 기본 법칙만을 사용하여 증명한다.

### 問題22
### 문제 22

次の不等式を証明せよ。  
다음 부등식을 증명하여라.

$$\lvert x + y \rvert \ge \lvert x \rvert - \lvert y \rvert$$

**証明**  
**증명**

$x = (x + y) + (-y)$ と分解し、三角不等式を適用する。  
$x = (x + y) + (-y)$ 로 분해하고 삼각부등식을 적용한다.

$$\lvert x \rvert = \lvert (x + y) + (-y) \rvert \le \lvert x + y \rvert + \lvert -y \rvert$$

$\lvert -y \rvert = \lvert y \rvert$ より、$\lvert x \rvert \le \lvert x + y \rvert + \lvert y \rvert$ となる。  
$\lvert -y \rvert = \lvert y \rvert$ 이므로 $\lvert x \rvert \le \lvert x + y \rvert + \lvert y \rvert$ 가 된다.

両辺から $\lvert y \rvert$ を引けば、$\lvert x + y \rvert \ge \lvert x \rvert - \lvert y \rvert$ が得られる。□  
양변에서 $\lvert y \rvert$ 를 빼면 $\lvert x + y \rvert \ge \lvert x \rvert - \lvert y \rvert$ 를 얻는다. □

### 問題23
### 문제 23

次の不等式を証明せよ。  
다음 부등식을 증명하여라.

$$\lvert x - y \rvert \ge \lvert x \rvert - \lvert y \rvert$$

**証明**  
**증명**

$x = (x - y) + y$ と分解し、三角不等式を適用する。  
$x = (x - y) + y$ 로 분해하고 삼각부등식을 적용한다.

$$\lvert x \rvert = \lvert (x - y) + y \rvert \le \lvert x - y \rvert + \lvert y \rvert$$

両辺から $\lvert y \rvert$ を引けば、$\lvert x - y \rvert \ge \lvert x \rvert - \lvert y \rvert$ が得られる。□  
양변에서 $\lvert y \rvert$ 를 빼면 $\lvert x - y \rvert \ge \lvert x \rvert - \lvert y \rvert$ 를 얻는다. □

### 問題24
### 문제 24

次の不等式を証明せよ。  
다음 부등식을 증명하여라.

$$\lvert x - y \rvert \le \lvert x \rvert + \lvert y \rvert$$

**証明**  
**증명**

$x - y = x + (-y)$ と考え、三角不等式を適用する。  
$x - y = x + (-y)$ 로 보고 삼각부등식을 적용한다.

$$\lvert x - y \rvert = \lvert x + (-y) \rvert \le \lvert x \rvert + \lvert -y \rvert = \lvert x \rvert + \lvert y \rvert$$

よって $\lvert x - y \rvert \le \lvert x \rvert + \lvert y \rvert$ が成り立つ。□  
따라서 $\lvert x - y \rvert \le \lvert x \rvert + \lvert y \rvert$ 가 성립한다. □

問題22〜24は、式を適切に分解して三角不等式を使うことがポイントである。  
문제 22~24는 식을 적절히 분해하여 삼각부등식을 사용하는 것이 핵심이다.

### 問題25 (a)
### 문제 25 (a)

$0 < a < b$ のとき、次を証明せよ。  
$0 < a < b$ 일 때 다음을 증명하여라.

$$a^2 < b^2$$

**証明**  
**증명**

仮定より $b - a > 0$ であり、$a, b$ はともに正なので $a + b > 0$ である。  
가정에 의해 $b - a > 0$ 이고, $a, b$ 가 모두 양수이므로 $a + b > 0$ 이다.

正の数どうしの積は正なので、次が成り立つ。  
양수끼리의 곱은 양수이므로 다음이 성립한다.

$$(b - a)(b + a) = b^2 - a^2 > 0$$

よって $a^2 < b^2$ である。□  
따라서 $a^2 < b^2$ 이다. □

### 問題25 (b)
### 문제 25 (b)

$0 < a < b$ のとき、すべての正の整数 $n$ に対して次を数学的帰納法で証明せよ。  
$0 < a < b$ 일 때 모든 양의 정수 $n$ 에 대하여 다음을 수학적 귀납법으로 증명하여라.

$$a^n < b^n$$

**証明**  
**증명**

(i) $n = 1$ のとき、仮定より $a^1 < b^1$ は成り立つ。  
(i) $n = 1$ 일 때, 가정에 의해 $a^1 < b^1$ 은 성립한다.

(ii) ある正の整数 $k$ に対して $a^k < b^k$ が成り立つと仮定する（帰納法の仮定）。  
(ii) 어떤 양의 정수 $k$ 에 대하여 $a^k < b^k$ 가 성립한다고 가정한다(귀납 가정).

$a > 0$ なので、帰納法の仮定の両辺に $a$ を掛けると $a^{k+1} < a b^k$ を得る。  
$a > 0$ 이므로 귀납 가정의 양변에 $a$ 를 곱하면 $a^{k+1} < a b^k$ 를 얻는다.

さらに $a < b$ かつ $b^k > 0$ なので、$a b^k < b^{k+1}$ が成り立つ。  
또한 $a < b$ 이고 $b^k > 0$ 이므로 $a b^k < b^{k+1}$ 이 성립한다.

2つの不等式をつなげると、次のようになる。  
두 부등식을 연결하면 다음과 같다.

$$a^{k+1} < a b^k < b^{k+1}$$

したがって $n = k + 1$ のときも成り立ち、数学的帰納法によりすべての正の整数 $n$ について $a^n < b^n$ である。□  
따라서 $n = k + 1$ 일 때도 성립하며, 수학적 귀납법에 의해 모든 양의 정수 $n$ 에 대하여 $a^n < b^n$ 이다. □

### 問題26
### 문제 26

$a, b, c, d$ がすべて正で $\dfrac{a}{b} < \dfrac{c}{d}$ のとき、次を証明せよ。  
$a, b, c, d$ 가 모두 양수이고 $\dfrac{a}{b} < \dfrac{c}{d}$ 일 때 다음을 증명하여라.

$$\frac{a}{b} < \frac{a + c}{b + d} < \frac{c}{d}$$

**証明**  
**증명**

$b, d > 0$ なので、仮定の両辺に $bd$ を掛けると $ad < bc$ を得る。  
$b, d > 0$ 이므로 가정의 양변에 $bd$ 를 곱하면 $ad < bc$ 를 얻는다.

① 左側の不等式について、分母はすべて正なので次のように同値変形できる。  
① 왼쪽 부등식에 대하여, 분모가 모두 양수이므로 다음과 같이 동치 변형할 수 있다.

$$\frac{a}{b} < \frac{a + c}{b + d} \iff a(b + d) < b(a + c) \iff ab + ad < ab + bc \iff ad < bc$$

最後の不等式は仮定から成り立つので、左側の不等式が示された。  
마지막 부등식은 가정으로부터 성립하므로 왼쪽 부등식이 증명되었다.

② 右側の不等式についても同様に変形する。  
② 오른쪽 부등식에 대해서도 마찬가지로 변형한다.

$$\frac{a + c}{b + d} < \frac{c}{d} \iff d(a + c) < c(b + d) \iff ad + cd < bc + cd \iff ad < bc$$

これも仮定から成り立つので、①と②を合わせて結論を得る。□  
이것도 가정으로부터 성립하므로 ①과 ②를 합쳐 결론을 얻는다. □

分子どうし・分母どうしを足した分数（メディアント, mediant）は、もとの2つの分数の間にある。  
분자끼리, 분모끼리 더한 분수(매개분수, mediant)는 원래 두 분수 사이에 놓인다.

### 問題27
### 문제 27

$a, b$ がともに正のとき、次を証明せよ。  
$a, b$ 가 모두 양수일 때 다음을 증명하여라.

$$\sqrt{ab} \le \frac{a + b}{2}$$

これは相加平均と相乗平均の関係（AM-GM不等式）である。  
이것은 산술평균과 기하평균의 관계(AM-GM 부등식)이다.

**証明**  
**증명**

実数の2乗は $0$ 以上なので、次が成り立つ。  
실수의 제곱은 $0$ 이상이므로 다음이 성립한다.

$$\left(\sqrt{a} - \sqrt{b}\right)^2 \ge 0$$

左辺を展開すると $a - 2\sqrt{ab} + b \ge 0$ となる。  
좌변을 전개하면 $a - 2\sqrt{ab} + b \ge 0$ 이 된다.

移項すると $a + b \ge 2\sqrt{ab}$ であり、両辺を2で割れば結論を得る。□  
이항하면 $a + b \ge 2\sqrt{ab}$ 이고, 양변을 2로 나누면 결론을 얻는다. □

**等号成立条件**  
**등호 성립 조건**

等号が成り立つのは $\left(\sqrt{a} - \sqrt{b}\right)^2 = 0$、すなわち $a = b$ のときに限る。  
등호가 성립하는 것은 $\left(\sqrt{a} - \sqrt{b}\right)^2 = 0$, 즉 $a = b$ 일 때뿐이다.

### 3.1 発展：逆三角不等式
### 3.1 발전: 역삼각부등식

問題23と同じ議論を $x$ と $y$ を入れ替えて行うと、$\lvert y \rvert - \lvert x \rvert \le \lvert y - x \rvert = \lvert x - y \rvert$ も得られる。  
문제 23과 같은 논의를 $x$ 와 $y$ 를 바꾸어 적용하면 $\lvert y \rvert - \lvert x \rvert \le \lvert y - x \rvert = \lvert x - y \rvert$ 도 얻을 수 있다.

2つを合わせると、次の逆三角不等式が成り立つ。  
두 식을 합치면 다음의 역삼각부등식이 성립한다.

$$\left\lvert \lvert x \rvert - \lvert y \rvert \right\rvert \le \lvert x - y \rvert$$

これは2数の距離や極限を扱うときに非常によく使われる。  
이것은 두 수 사이의 거리나 극한을 다룰 때 매우 자주 사용된다.

### 3.2 まとめ
### 3.2 정리

| 問題 | 証明する内容 | 核心アイデア（핵심 아이디어） |
|:---:|:---|:---|
| 22 | $\lvert x+y \rvert \ge \lvert x \rvert - \lvert y \rvert$ | $x = (x+y) + (-y)$ |
| 23 | $\lvert x-y \rvert \ge \lvert x \rvert - \lvert y \rvert$ | $x = (x-y) + y$ |
| 24 | $\lvert x-y \rvert \le \lvert x \rvert + \lvert y \rvert$ | $x - y = x + (-y)$ と三角不等式 |

| 25(b) | $a^n < b^n$ | 数学的帰納法（수학적 귀납법） |
| 26 | $\dfrac{a}{b} < \dfrac{a+c}{b+d} < \dfrac{c}{d}$ | $ad < bc$ への同値変形 |
| 27 | $\sqrt{ab} \le \dfrac{a+b}{2}$ | $\left(\sqrt{a}-\sqrt{b}\right)^2 \ge 0$ |
